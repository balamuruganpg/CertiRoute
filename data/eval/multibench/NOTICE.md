- ARC-Challenge prompts and frozen paired responses/correctness come from
  [RouterBench](https://huggingface.co/datasets/withmartian/routerbench), revision
  `784021482c3f320c6619ed4b3bb3b41a21424fcb`, by Martian. The upstream dataset card does
  not state a separate dataset license; the RouterBench software repository's MIT
  license should not be assumed to relicense all underlying datasets/model outputs.
  Original benchmark: [AI2 ARC](https://allenai.org/data/arc).
- MBPP prompts, imports and tests come from Google Research's sanitized MBPP file,
  revision `f82046ba5aabbbb427dbfd38a254d26bff08b533` (Apache 2.0 project).
- Paired MBPP generated outputs come from EvalPlus v0.2.0 release archives
  `gpt-3.5-turbo_temp_0.0.zip` and `gpt-4-1106-preview_temp_0.0.zip`.
  [EvalPlus](https://github.com/evalplus/evalplus) is Apache 2.0; retain attribution
  and respect underlying model/data terms. These archives contain real model outputs,
  not outputs generated by CertiRoute's author.
- `sources.lock.json` records exact URLs/hashes; JSONL manifests bind converted data.
  Conversion extracts records, estimates token counts, and adds independently executed
  MBPP base-test labels. No model response text is edited.
